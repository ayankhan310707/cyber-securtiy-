## Brand & Style

The design system projects mission-critical authority, hyper-precise telemetry, and tactical defense readiness. Geared toward enterprise SecOps teams, threat intelligence engineers, and cybersecurity leaders, the UI evokes absolute control, deep situational awareness, and relentless defense posture under pressure.

The visual style blends **Technical Minimalism** with **Tactical Cyberpunk Precision**:
- Atmospheric, ultra-deep obsidian foundations punctuated by sharp luminescence.
- Calculated glow effects applied strictly as status indicators and telemetry vectors, rather than decorative washes.
- Precision framing inspired by head-up display (HUD) viewports and hardware command consoles.
- Terminal-inspired metadata accents counterbalancing ultra-clean humanist and geometric typography.

## Colors

The palette establishes an ultra-high-contrast nocturnal operations interface where light equates to telemetry and security state.

### Color Architecture
- **Primary (`#00ff88` / `#22c55e` / `#4ade80`)**: Neon Lime & Cyber Mint. Denotes active protection, secure states, verified hashes, high-priority telemetry, and active primary controls.
- **Secondary (`#00f0ff` / `#06b6d4`)**: Electric Cyan. Signals network conduits, dynamic data streams, zero-day threat analysis, and automated responses.
- **Tertiary (`#10b981`)**: Deep Emerald. Used for passive healthy indicators, secondary verification metrics, and baseline metrics.
- **Neutral Foundations**:
  - Root Canvas / Void: `#050807`
  - Base Surface: `#080c0a`
  - Elevated Container Tier 1: `#0d1f17`
  - Elevated Container Tier 2: `#132a20`
  - Elevated Container Tier 3: `#1a382b`
- **Text & Foreground**:
  - High Contrast (Primary Content): `#e6f4ed`
  - Medium Contrast (Muted Data / Labels): `#7e9c8f`
  - Dim Contrast (Borders / Inactive Lines): `#1a3628`
- **Alert States**:
  - Critical Incursion / Attack: `#ff3366`
  - Elevated Warning / Anomaly: `#ffb703`

## Typography

The typographic hierarchy pairs high-performance technical engineering with readable data feeds.

- **Headings (`Space Grotesk`)**: Geometric, calculated, and authoritative. Sets structural anchors for threat consoles, dashboard widgets, and high-level telemetry overviews.
- **Body Text (`Inter`)**: High-legibility neutral workhorse designed for effortless scanning across high-density incident logs, forensic documentation, and threat narratives.
- **Data, Labels & Metrics (`JetBrains Mono`)**: Strict, tabular-aligned monospaced typeface dedicated to IP addresses, CVE IDs, cryptographic signatures, terminal outputs, and uppercase category labels.

## Layout & Spacing

The layout is built on a responsive 12-column grid engine tuned for high-density command center dashboards, collateral inspection panes, and split-screen threat monitors.

### Grid & Breakpoints
- **Desktop (1440px+)**: 12-column fluid grid, 24px gutters, 32px canvas margins. High-density viewports utilize collapsible left navigation and split auxiliary inspector drawers.
- **Tablet (768px - 1439px)**: 8-column layout, 16px gutters, 24px margins. Cards reflow from horizontal operational ribbons to stacked telemetry blocks.
- **Mobile (< 768px)**: 4-column layout, 12px gutters, 16px margins. Telemetry panes collapse into tabbed segment controllers with prioritized single-column logs.

### Rhythm Principles
- Component spacing obeys a disciplined 4px base rhythm: internal padding uses compact scales (`space-xs`, `space-sm`, `space-md`) to ensure dense, information-rich visual density without spatial clutter.
- Sections and structural widgets utilize `space-lg` to `space-xl` to maintain clean visual segmentation between unrelated attack vectors.

## Elevation & Depth

Depth is established through deep forest-green surface layering, neon rim lighting, and luminous energy fields rather than traditional heavy drop shadows.

### Surface Tiers
- **Level 0 (Canvas Void)**: `#050807` with a faint 24px CSS background grid pattern (`rgba(0, 255, 136, 0.03)`).
- **Level 1 (Structural Cards)**: `#0d1f17` background with a subtle 1px border (`#1a3628`).
- **Level 2 (Active/Hover Cards)**: `#132a20` background with a 1px border (`rgba(0, 255, 136, 0.25)`).
- **Level 3 (Modals / Overlays / Flyouts)**: `#132a20` supported by `backdrop-filter: blur(16px)` and a directional glow border (`rgba(0, 240, 255, 0.35)`).

### Luminous Edge Treatments
- **Standard Border**: 1px solid `#1a3628`.
- **Active Edge Glow**: 1px solid `rgba(0, 255, 136, 0.4)` coupled with `box-shadow: 0 0 16px -2px rgba(0, 255, 136, 0.15)`.
- **Critical Alert Glow**: 1px solid `rgba(255, 51, 102, 0.5)` with `box-shadow: 0 0 20px -2px rgba(255, 51, 102, 0.2)`.

## Shapes

The design system implements a cohesive curvature philosophy (`roundedness: 2`), marrying futuristic aerospace ergonomics with rugged military hardware design.

- **Base Radius (`0.5rem` / 8px)**: Standard inputs, buttons, pills, chips, and table row groupings.
- **Large Radius (`1rem` / 16px)**: Primary operational cards, telemetry containers, and status monitors.
- **Extra-Large Radius (`1.5rem` / 24px)**: Major viewport panels, floating modal sheets, and perimeter threat radar widgets.
- **Technical Chamfers (Accent Elements)**: Optional cut-corner geometric treatments for terminal pill badges and hardware status indicators.

## Components

### Buttons
- **Primary Action**: Solid `#00ff88` background, `#050807` text (`JetBrains Mono`, bold, uppercase), rounded to 8px. Hover adds `box-shadow: 0 0 20px rgba(0, 255, 136, 0.45)` with a subtle translate-y shift.
- **Secondary (Tactical Cyan)**: Outlined with 1px `rgba(0, 240, 255, 0.5)`, translucent fill `rgba(0, 240, 255, 0.08)`, text `#00f0ff`. Hover intensifies border and adds glow.
- **Ghost/Tertiary**: Surface `#0d1f17`, border `#1a3628`, text `#7e9c8f`. Hover state shifts text to `#e6f4ed` and border to `#22c55e`.

### Chips & Terminal Badges
- Displayed exclusively in `JetBrains Mono` uppercase with high tracking.
- Composed of an ultra-dark fill (`#080c0a`), a 1px tint-matching border, and an integrated pulsing SVG status radar dot.
- Threat levels:
  - `CRITICAL`: Fill `rgba(255, 51, 102, 0.1)`, text `#ff3366`, border `#ff3366`.
  - `ACTIVE`: Fill `rgba(0, 255, 136, 0.1)`, text `#00ff88`, border `#00ff88`.
  - `MONITORING`: Fill `rgba(0, 240, 255, 0.1)`, text `#00f0ff`, border `#00f0ff`.

### Form Controls (Inputs, Checkboxes, Radios)
- **Input Fields**: Background `#080c0a`, border 1px solid `#1a3628`, text `#e6f4ed`, placeholder `#466355`. Focus triggers a sharp 1px ring in `#00ff88` with an 8px radial green shadow.
- **Checkboxes & Radios**: 18px containers with `#0d1f17` background and `#1a3628` border. Checked state transitions background to `#00ff88` with a contrasting pitch-black interior icon.

### Telemetry Cards
- Encased in deep forest-green surfaces (`#0d1f17`) with 16px corner radii.
- Headers feature a subtle top hairline gradient border (`transparent` to `rgba(0, 255, 136, 0.4)` to `transparent`).
- Internal divider lines use micro 1px rules in `#132a20`.

### Data Grids & Terminal Incident Logs
- Alternating subtle row zebra striping using `#080c0a` and `#0a140f`.
- Numeric values and timestamps render in monospaced tabular numbers (`font-variant-numeric: tabular-nums`).
- Hover row state renders an illuminated left indicator bar (2px solid `#00f0ff`) with background shift to `#132a20`.
